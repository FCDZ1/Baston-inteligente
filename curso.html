Curso: Construí tu propio Bastón Inteligente

Aprendé, de forma práctica, a diseñar, armar y programar un bastón inteligente con Arduino y sensores ultrasónicos. Pensado para estudiantes sin experiencia previa en electrónica.

VER GUÍA DE ESTUDIO

¿A quién está dirigido?

A estudiantes, docentes y makers interesados en tecnología asistiva.
No se requieren conocimientos previos: el curso empieza desde cero.

Primer vistazo al código

Así se ve una lectura básica del sensor ultrasónico en Arduino, uno de los primeros ejercicios del curso:

const int trigPin = 9;
const int echoPin = 10;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

void loop() {
  long duracion, distanciaCm;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duracion = pulseIn(echoPin, HIGH);
  distanciaCm = duracion * 0.034 / 2;

  Serial.print("Distancia: ");
  Serial.print(distanciaCm);
  Serial.println(" cm");
  delay(200);
}
