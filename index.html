¿Qué es un Bastón Inteligente?

Un bastón inteligente es un dispositivo tecnológico diseñado para ayudar a personas con discapacidad visual a desplazarse de manera más segura y autónoma.
Este tipo de bastón mejora la movilidad y ayuda a prevenir choques o accidentes durante el desplazamiento.

¿Cómo funciona?

Utiliza sensores para detectar obstáculos.

Componentes

Arduino, sensor ultrasónico, motor vibrador.

Sensores

HC-SR04 y otros sensores de apoyo.

Beneficios

Mayor seguridad y autonomía.

Instrucciones de uso

Sostener el bastón y encender el sistema.
